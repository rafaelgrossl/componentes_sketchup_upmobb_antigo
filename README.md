# upmobb_biblioteca_antiga

Regras e histórico para **criar e modificar componentes dinâmicos da biblioteca antiga do Upmobb** com o Claude Code.
A biblioteca nova (Grossl) fica em `Desktop\upmobb_componentes`.

- `CLAUDE.md` — o que o Claude segue em cada pedido (lido sozinho ao abrir a sessão nesta pasta).
- `regras/` — fundamentos, **estrutura antiga**, receitas, ponte, nomes e códigos, minifotos.
- `scripts/` — comandos para a ponte (árvore, atributos, dump, comparação, moldes do catálogo, fotos, minifotos).
- `componentes/` — o que já foi feito, com as fórmulas, para refazer.
- `referencia/` — dumps completos das gavetas antigas da cena, estudo de moldes do catálogo e o catálogo classificado.
- `minifotos/` — minifotos feitas aqui e os logos.

Uso: abra o Claude Code nesta pasta com o SketchUp aberto e a ponte ligada
(Extensões > Componentes Upmobb > Ponte com o Claude).
